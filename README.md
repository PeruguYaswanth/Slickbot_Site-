# 🚀 Slickbot.com Clone (React.js)

A responsive front-end clone of the Slickbot.com website built using React.js. This project was developed manually from scratch without using AI tools or pre-built templates, focusing on UI replication and frontend development skills.

---

## 📌 Features

- Pixel-perfect UI similar to the original website
- Fully responsive design (mobile, tablet, desktop)
- Built with reusable React components
- Clean and structured code
- Smooth UI interactions

---

## 🛠 Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
